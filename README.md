# Violation Tracking

A [Chickadee Bandit](https://chickadeebandit.com/app-library/violation-tracking) app.

Board issues CC&R violation notices to units; homeowners acknowledge, respond, or dispute; board tracks through resolution or escalation.

## Features

- Notices issued to units by the board.
- Homeowner acknowledgement, response, or dispute.
- Tracking to resolution or escalation.
- Full audit trail per unit.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-violation-tracking/releases/latest/download/bundle.json
```
